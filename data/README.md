# Data Directory

## Real OptionMetrics Data (required for paper replication)

Place the OptionMetrics SPX end-of-day option file at:

```
data/optionmetrics_spx.csv
```

Required columns:

| Column | Description |
|--------|-------------|
| `date` | Trade date (YYYY-MM-DD) |
| `option_type` | `C` for call, `P` for put |
| `strike` | Raw strike price κ_i |
| `maturity_date` | Option expiry date (YYYY-MM-DD) |
| `bid` | End-of-day bid price |
| `ask` | End-of-day ask price |
| `volume` | Daily trading volume |
| `D` | Cross-section discount factor (exp(-r·τ)) |
| `F` | Cross-section forward price |

**Note**: This file must NOT be committed to version control (see `.gitignore`).

## Synthetic Data

The `synthetic/` subdirectory holds deterministic test fixtures generated by
`src/synthetic_data.py`. These are small enough to regenerate on demand and
are left empty in the repository; the test suite generates data in-memory.

## Regenerating Synthetic Data

```python
from src.synthetic_data import generate_synthetic_spx_options
df = generate_synthetic_spx_options(n_weeks=50, seed=42)
df.to_csv("data/synthetic/spx_synthetic.csv", index=False)
```
